# Установка на Mac — 4 команды

Откройте **Терминал** (Cmd+Пробел → «Терминал») и по очереди вставляйте команды.
Если где-то попросят пароль от Mac — введите его (символы не видны, это нормально).

**1. Установить Homebrew** (если уже стоит — пропустите)
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
В конце Homebrew покажет блок «Next steps» с двумя командами — скопируйте и выполните их.

**2. Поставить инструмент GitHub**
```bash
brew install git gh
```

**3. Войти в GitHub** — откроется браузер, нажмите «Authorize»
```bash
gh auth login -h github.com -p https -w
```

**4. Скачать и запустить установщик**
```bash
mkdir -p ~/code && gh repo clone Lonkbot228/poymai-deploy ~/code/poymai-deploy && bash ~/code/poymai-deploy/install-mac.sh
```

Дальше скрипт сам: поставит Node и Rust, создаст SSH-ключ, спросит **пароль от серверов один раз**
(PoymAI и Telegram-шлюз), скачает проекты в `~/code`, соберёт приложение (5–10 минут) и запустит.

Если скрипт остановился с ошибкой — просто запустите четвёртую команду ещё раз:
готовые шаги он пропускает.

## Как пользоваться
- Значок в строке меню (справа сверху) → клик → окно.
- **Задеплоить** — коммит, GitHub, сервер, проверка. Всё автоматически.
- Задеплоили с Windows — Mac сам подтянет изменения в течение минуты и покажет уведомление.
- Если на Mac есть несохранённые правки, приложение спросит — нажмите «Получить».
